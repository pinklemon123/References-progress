# 问题三程序说明（两套算法）

## 算法A：基准算法

`q3_solver.py`（亦可由 `q3_solver_baseline.py` 启动）读取附件1坐标、附件2动态圆形管制区和问题二路线，以8:00为时间原点，在固定机队规模下按 `(Tmax, delta, total_work)` 词典序搜索动态可行方案。该算法采用直线航段解析冲突检查、必要安全等待和任务序列优化，不构造空间绕飞路径。

既有正式结果位于 `../results/`，不得与增强算法结果混用。

## 算法B：增强算法

`q3_solver_enhanced.py` 使用唯一任务副本，比较直接航段等待与圆形障碍边界离散可见图绕飞，并明确分为阶段A（仅优化 `Tmax`）和阶段B（在 `Tmax <= (1+epsilon) * Tmax_star` 内优化 `delta`）。运行时应通过 `--baseline-q3-solution` 同时提供算法A结果作为必选种子，确保增强算法的阶段A结果不劣于已有基准可行解。固定问题二机队规模的结果是正式主方案；增加无人机仅通过可选参数用于敏感性分析。

增强算法结果写入单独目录 `../results_enhanced/`，不会覆盖算法A结果。Case 4 的 Z8 按半开区间 `[17:00,17:00)` 处理为空集，两套算法均不将其延长到任务结束。

`q3_fast_validator.py` 是独立复核程序。它使用包围盒预筛和解析线段—圆相交区间，逐事件检查飞行、巡检服务和必要等待是否与管制时段冲突。
